# SiteForge

AI-Powered Website Builder & SaaS Platform.

## Structure

- **frontend/**: Next.js frontend application.
- **backend/**: Express/NodeJS backend application.
- **database/**: Database schemas, migrations, and seeders.
- **docs/**: Project documentation.
- **deployment/**: Deployment configurations (Docker, Nginx, CI/CD).
- **assets/**: Design assets, logos, and mockups.
